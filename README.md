### 📌 Overview

I am a Software Engineering student focused on building high-performance web applications and resilient backend architecture. I enjoy bridging the gap between clean frontend experiences and scalable backend/DevOps environments (VPS, Reverse Proxies, Cloudflare Ecosystem).

- 🔭 **Current Focus:** Full-Stack web architecture, microservices, and server-side performance.
- ⚡ **Engineering Practice:** Linux-first workflow (Fedora GNOME), automated deployments, and modular code design.
- 💬 **Ask me about:** React, Next.js, Node.js, Reverse Proxies (Nginx), and Cloudflare Tunnels.
